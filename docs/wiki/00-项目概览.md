# Go-scrcpy Code Wiki — 项目概览

## 什么是 Go-scrcpy？

**Go-scrcpy** 是一个纯 Go 语言实现的 [scrcpy](https://github.com/Genymobile/scrcpy) 客户端库，通过 ADB 协议连接 Android 设备，实现屏幕镜像、远程控制、文件管理等功能。该项目定位为**可复用的 Go library**，发布在 `github.com/yuan71058/go-scrcpy`。

## 核心特性

| 特性 | 说明 |
|------|------|
| 协议版本 | scrcpy v4.1，完整支持 22 种控制消息 + ws-scrcpy 扩展 |
| 多设备支持 | 同时接入多个 Android 设备，独立控制，互不影响 |
| 视频流 | H.264、H.265、AV1、VP8、VP9 编码 |
| 音频流 | Opus、AAC、FLAC、PCM 编码 |
| 输入注入 | 触摸、键盘、鼠标、滚动、文本 |
| 剪贴板 | 双向同步 |
| 文件推送 | 文件上传 + APK 安装 |
| 录制截图 | MP4/MKV 录制、PNG 截图 |
| 摄像头控制 | 闪光灯、变焦、前后摄切换 |
| UHID 虚拟 HID | 虚拟键盘/鼠标/游戏手柄 |
| 设备自动发现 | 实时监听设备上下线 |

## 三通道连接架构

使用 **reverse tunnel** 模式（`adb reverse`），Android 设备主动连接 PC：

```
PC (监听)                    ADB                         Android
   │                          │                            │
   │── tcp:27183 ── adb reverse ── localabstract:scrcpy ──→│  Video
   │── tcp:27184 ── adb reverse ── localabstract:scrcpy_1 ─→│  Audio
   │── tcp:27185 ── adb reverse ── localabstract:scrcpy_2 ─→│  Control
```

## 技术栈

| 层面 | 技术选型 |
|------|----------|
| 语言 | Go 1.22+ |
| ADB 通信 | `os/exec` 调用 adb 命令行 |
| 网络传输 | 标准库 `net` (TCP socket) |
| 视频解码 (核心) | 纯 Go 实现（NALU 解析、帧队列） |
| 视频解码 (渲染) | FFmpeg (`avcodec-62.dll`) via syscall |
| 窗口渲染 (演示) | SDL3 (`SDL3.dll`) via syscall |
| 外部依赖 | **零第三方 Go 依赖** |

## 设计原则

1. **接口优于实现**: `Decoder`、`Renderer` 定义为接口，用户可替换
2. **Option 模式**: 所有配置通过 `Options` struct，零值即合理默认
3. **Channel 驱动**: 视频帧、音频包通过 Go channel 流式传递
4. **Context 贯穿**: 所有阻塞操作接受 `context.Context`，支持超时和取消
5. **错误不隐藏**: 所有错误返回 `error`，不 panic
6. **无 CGo 必选**: 核心库纯 Go，解码器可选 CGo 实现
7. **并发安全**: `MultiClient` 操作加锁，per-device session 无锁


## 运行环境要求

- Go >= 1.22
- ADB 已安装并在 PATH 中
- Android 设备已开启 USB 调试
- `scrcpy-server.jar`（项目自带，位于 `data/` 目录）
