# Go-scrcpy Code Wiki — 依赖与运行方式

## 外部依赖

### Go 依赖

**零第三方 Go 依赖** — 项目仅依赖 Go 标准库：

| 标准库包 | 用途 |
|----------|------|
| `os/exec` | 调用 adb 命令行（ADB 设备管理） |
| `net` | TCP socket 通信（三通道传输） |
| `encoding/binary` | 大端序/小端序编解码（协议层） |
| `io` | 数据流读写 |
| `sync` | 并发控制（Mutex, RWMutex, WaitGroup） |
| `context` | 生命周期管理（超时、取消） |
| `image` | 截图图像生成 |
| `image/png` | PNG 编码 |
| `syscall` | DLL 动态加载（FFmpeg/SDL3 渲染） |
| `os/signal` | 信号处理（示例程序） |

### 系统依赖

| 依赖 | 说明 | 用途 |
|------|------|------|
| ADB | Android Debug Bridge | 设备发现、连接、文件操作 |
| scrcpy-server.jar | Android 端 Java 服务 | 视频/音频捕获、输入注入 |
| (可选) FFmpeg DLLs | `avcodec-62.dll`, `avutil-60.dll` | H.264 硬件解码（渲染示例） |
| (可选) SDL3 DLL | `SDL3.dll` | 窗口渲染（渲染示例） |

### 文件路径

| 文件 | 路径 | 说明 |
|------|------|------|
| scrcpy-server.jar | `data/scrcpy-server.jar` | Android 端服务 (733KB) |
| FFmpeg DLLs | `data/scrcpy-win64-v4.1/` | Windows 解码库 |
| SDL3 DLL | `data/scrcpy-win64-v4.1/` | Windows 图形库 |

## 运行环境要求

### 开发环境

- **Go 版本**: >= 1.22
- **操作系统**: Windows（主要开发平台）、Linux、macOS
- **ADB**: 已安装并在 PATH 中
- **Android 设备**: 已开启 USB 调试

### Android 设备要求

| 功能 | 最低 Android 版本 |
|------|-------------------|
| 屏幕镜像 | Android 5.0+ |
| 音频捕获 | Android 11+ (API 30+) |
| UHID 虚拟 HID | Android 9+ (API 28+) |
| 摄像头控制 | Android 12+ |
| 反向隧道 | Android 5.0+ |

## 运行方式

### 1. 运行 CLI 示例

```bash
# 从项目根目录
cd cmd/go-scrcpy
go run main.go
```

### 2. 运行单设备示例

```bash
cd _examples/single
go run main.go <device_serial>
```

### 3. 运行多设备示例

```bash
cd _examples/multi
go run main.go
```

### 4. 运行控制示例

```bash
cd _examples/control
go run main.go <device_serial>
```

### 5. 运行录制示例

```bash
cd _examples/record
go run main.go <device_serial>
# 输出: recording.mp4, screenshot.png
```

### 6. 运行投屏示例（需要 FFmpeg + SDL3 DLL）

```bash
cd _examples/mirror
go run main.go
```

### 7. 作为库引用

```bash
go get github.com/yuan71058/go-scrcpy
```

```go
import "github.com/yuan71058/go-scrcpy/pkg/scrcpy"

opts := scrcpy.DefaultOptions()
client := scrcpy.New("device_serial", opts)
client.Start(ctx)
for frame := range client.VideoStream() {
    // 处理帧
}
```

## ADB 配置

### 检查设备连接

```bash
adb devices -l
```

### 启用 USB 调试

1. 打开设备「设置」→「关于手机」
2. 连续点击「版本号」7 次开启开发者模式
3. 返回「设置」→「开发者选项」
4. 开启「USB 调试」

### 无线连接（可选）

```bash
adb connect <device_ip>:5555
```

## 常见问题

### 1. "找不到设备"

- 确认 USB 调试已开启
- 检查 `adb devices` 是否能列出设备
- 尝试重新插拔 USB 线

### 2. "启动 server 失败"

- 确认 `scrcpy-server.jar` 存在
- 尝试 `adb shell pkill -f scrcpy` 清理旧进程
- 检查是否有多余的 ADB 端口转发

### 3. 视频解码失败

- 降低码率（`VideoBitRate`）
- 尝试切换编码器（`VideoCodec`）
- 确认设备支持的编码器类型

### 4. 多设备端口冲突

- 使用 `listenPort=0` 自动分配端口
- MultiClient 的 `Add()` 方法会自动查找可用端口

## 构建注意事项

### 构建二进制

```bash
# 构建 CLI 示例
go build -o go-scrcpy.exe ./cmd/go-scrcpy/

# 投屏示例（需要 DLL）
go build -o mirror.exe ./_examples/mirror/
```

### 交叉编译

```bash
# Linux
GOOS=linux GOARCH=amd64 go build ./cmd/go-scrcpy/

# macOS
GOOS=darwin GOARCH=amd64 go build ./cmd/go-scrcpy/
```

**注意：** 投屏示例（`_examples/mirror`）因使用了 `syscall.LazyDLL` 加载 Windows DLL，无法在非 Windows 平台编译。
