# Go-scrcpy Code Wiki — 渲染模块（pkg/render）

`pkg/render` 提供 FFmpeg H264 解码和 SDL3 窗口渲染功能，通过 `syscall.LazyDLL` 动态加载 DLL 实现，**无需 CGo**。此模块为独立于核心库的演示/示例模块，仅由 `_examples/mirror` 示例使用。

## 包结构

```
pkg/render/
├── convert.go    # YUV420P → RGB24 色彩空间转换
├── decoder.go    # FFmpeg avcodec H264 解码器
└── renderer.go   # SDL3 窗口渲染器
```

## 依赖的 DLL 文件

所有 DLL 位于 `data/scrcpy-win64-v4.1/` 目录：

| DLL | 用途 |
|-----|------|
| `avcodec-62.dll` | FFmpeg 编解码库（H.264 解码） |
| `avutil-60.dll` | FFmpeg 工具库（帧分配） |
| `SDL3.dll` | SDL3 图形库（窗口创建、渲染） |

## 类型定义

### YUV420PtoRGB — 色彩空间转换

```go
func YUV420PtoRGB(yuv []byte, w, h int) []byte
```

- 输入：YUV420P  planar 格式数据
- 输出：RGB24  packed 格式数据（`w*h*3` 字节）
- 使用 BT.601 色彩空间转换公式
- 包含边界检查（防止越界访问）

### FFmpeg H264Decoder

```go
type H264Decoder struct {
    codecCtx uintptr  // AVCodecContext*
    frame    uintptr  // AVFrame*
    pkt      uintptr  // AVPacket*
    width    int
    height   int
    mu       sync.Mutex
    closed   bool
}
```

**构造函数：**

```go
func NewH264Decoder() (*H264Decoder, error)
```

创建流程：
1. `avcodec_find_decoder(AV_CODEC_ID_H264)` — 查找 H.264 解码器
2. `avcodec_alloc_context3(codec)` — 分配解码器上下文
3. `avcodec_open2(ctx, codec, nil)` — 打开解码器
4. `av_frame_alloc()` — 分配帧对象
5. `av_packet_alloc()` — 分配包对象

**核心方法：**

| 方法 | 说明 |
|------|------|
| `Decode(data)` | 解码 H264 数据，返回 YUV420P 数据和宽高 |
| `GetSize()` | 获取视频尺寸 |
| `Close()` | 关闭解码器 |

**Decode() 流程：**

```
1. av_packet_from_data(pkt, data, len)  — 绑定数据到包
2. avcodec_send_packet(ctx, pkt)         — 发送到解码器
3. avcodec_receive_frame(ctx, frame)     — 接收解码帧
4. 从 codecCtx 偏移量读取宽高           — 硬件相关（可能不稳定）
5. 复制 Y/U/V 平面数据到连续缓冲区      — 处理 stride 和 padding
```

**注意：** 宽高从 `codecCtx + 48/52` 偏移量读取，为硬件相关实现。

### SDLRenderer — SDL3 渲染器

```go
type SDLRenderer struct {
    window   uintptr  // SDL_Window*
    renderer uintptr  // SDL_Renderer*
    texture  uintptr  // SDL_Texture*
    width    int
    height   int
}
```

**构造函数：**

```go
func NewSDLRenderer(title string, w, h int) (*SDLRenderer, error)
```

创建流程：
1. `SDL_Init(SDL_INIT_VIDEO)` — 初始化视频子系统
2. `SDL_CreateWindow(title, w, h, 0)` — 创建窗口
3. `SDL_CreateRenderer(win, nil)` — 创建渲染器
4. `SDL_CreateTexture(ren, SDL_PIXELFORMAT_YV12, STREAMING, w, h)` — 创建纹理

**方法：**

| 方法 | 说明 |
|------|------|
| `RenderYUV(yuv)` | 渲染 YUV 数据 |
| `Destroy()` | 销毁窗口和渲染器 |

**RenderYUV() 流程：**

```
1. SDL_UpdateYUVTexture(tex, nil, Y, Ystride, U, Ustride, V, Vstride)  — 更新纹理
2. SDL_RenderClear(ren)                    — 清空渲染器
3. SDL_RenderTexture(ren, tex, nil, nil)   — 渲染纹理
4. SDL_RenderPresent(ren)                  — 呈现到屏幕
```

**支持的 SDL 函数：**

窗口管理：`SDL_CreateWindow`, `SDL_DestroyWindow`, `SDL_GetWindowSize`, `SDL_SetWindowTitle`, `SDL_SetWindowMouseGrab`

渲染：`SDL_CreateRenderer`, `SDL_DestroyRenderer`, `SDL_RenderClear`, `SDL_RenderTexture`, `SDL_RenderPresent`

纹理：`SDL_CreateTexture`, `SDL_DestroyTexture`, `SDL_UpdateTexture`, `SDL_UpdateYUVTexture`

其他：`SDL_PollEvent`, `SDL_Delay`, `SDL_GetTicks`, `SDL_GetKeyboardState`, `SDL_free`, `SDL_GetError`

## 使用示例（完整投屏流程）

```go
// 1. 创建 scrcpy 客户端
client := scrcpy.New(serial, opts, 27183)
client.Start(ctx)

// 2. 创建 FFmpeg 解码器
decoder, _ := render.NewH264Decoder()

// 3. 创建 SDL 渲染器
sdl, _ := render.NewSDLRenderer("scrcpy", 1920, 1080)

// 4. 主循环：接收帧 → 解码 → 渲染
for frame := range client.VideoStream() {
    if !frame.Config {
        yuv, w, h, _ := decoder.Decode(frame.Data)  // H264 → YUV
        rgb := render.YUV420PtoRGB(yuv, w, h)        // YUV → RGB
        sdl.RenderYUV(rgb)                            // RGB → 屏幕
    }
}
```
