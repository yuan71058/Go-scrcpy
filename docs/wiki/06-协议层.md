# Go-scrcpy Code Wiki — 协议层（pkg/protocol）

`pkg/protocol` 实现 scrcpy 二进制协议的编解码，包括握手解析、控制消息构建、设备消息解析和帧元数据解析。

## 包结构

```
pkg/protocol/
├── log.go           # 日志函数
├── codec.go         # 所有常量（编解码器ID、消息类型、触摸/按键动作、指针ID、协议限制）
├── handshake.go     # 握手数据解析
├── control_msg.go   # 22+2 种控制消息序列化
├── device_msg.go    # 3 种设备消息反序列化 + 解析函数
└── frame_header.go  # 帧元数据头解析（12 字节）
```

## 类型定义

### Handshake — 握手数据

```go
type Handshake struct {
    DeviceName    string                            // 设备型号
    DisplayWidth  uint32                            // 显示宽度
    DisplayHeight uint32                            // 显示高度
    DeviceNameRaw [DeviceNameFieldLength]byte        // 原始设备名数据
}
```

**`ReadHandshake(reader)` 解析流程：**

```
1. 读取 64 字节设备名 (UTF-8, null padded)
2. 读取 4 字节视频 codec ID (big-endian)
3. 读取 12 字节 session packet:
   [0]     = 0x80 (session packet flag)
   [1..3]  = padding
   [4..7]  = video width (big-endian)
   [8..11] = video height (big-endian)
```

### FrameHeader — 帧元数据头

```go
type FrameHeader struct {
    PTS    int64   // 显示时间戳 (微秒)
    Size   uint32  // 编码包大小 (字节)
    Config bool    // 是否为配置帧 (SPS/PPS)
    Key    bool    // 是否为关键帧
}
```

**`ReadFrameHeader(reader)` 解析（12 字节协议格式）：**

```
[8B] PTS + flags (big-endian uint64):
  bit 62 (0x4000000000000000): config packet flag
  bit 61 (0x2000000000000000): key frame flag
  bits 60-0: PTS timestamp (microseconds)
[4B] Packet size (big-endian uint32)
```

### DeviceMessage — 设备消息

```go
type DeviceMessage struct {
    Type    byte    // 消息类型
    Payload []byte  // 消息载荷
}
```

**子消息结构：**

| 结构体 | 用途 |
|--------|------|
| `ClipboardMessage` | 剪贴板文本内容 |
| `AckClipboardMessage` | 剪贴板确认（含 sequence） |
| `UHIDOutputMessage` | UHID 输出（含 id + data） |
| `PushResponseMessage` | 文件推送响应（ws-scrcpy 扩展） |
