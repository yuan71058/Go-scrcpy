# Go-scrcpy Code Wiki — 音频处理（pkg/audio）

`pkg/audio` 提供音频解码接口、Opus 解码器和 PCM 播放器功能。

## 包结构

```
pkg/audio/
├── decoder.go    # Decoder 接口、Player 接口、AudioData 结构体
├── opus.go       # OpusDecoder — 通道式音频包队列
└── pcm.go        # PCMPlayer — 缓冲 PCM 播放器
```

## 接口定义

### Decoder — 音频解码器接口

```go
type Decoder interface {
    Push(data []byte) error           // 推送编码数据到解码器
    ReadPCM() (*AudioData, error)     // 读取解码后的 PCM 数据（阻塞）
    Close() error                     // 关闭解码器
}
```

用户可以替换此接口的自定义实现（如 opus CGo 绑定）。

### Player — 音频播放器接口

```go
type Player interface {
    Play(pcm []byte) error   // 播放 PCM 数据
    Close() error            // 关闭播放器
}
```

## 类型定义

### AudioData — 解码后的音频数据

```go
type AudioData struct {
    PTS           int64   // 显示时间戳 (微秒)
    Data          []byte  // PCM 数据
    SampleRate    int     // 采样率
    Channels      int     // 声道数
    BitsPerSample int     // 位深度
}
```

## 关键类型

### OpusDecoder — Opus 解码器（基础实现）

```go
type OpusDecoder struct {
    packets chan *AudioData  // 解码后的音频队列
    mu      sync.Mutex
    closed  bool
}
```

**构造函数：**

```go
func NewOpusDecoder(capacity int) *OpusDecoder
```

- `capacity`: 音频包队列容量（默认 100）

**方法：**

| 方法 | 说明 |
|------|------|
| `Push(data)` | 推送编码数据到解码器 |
| `ReadPCM()` | 读取 PCM 数据（阻塞） |
| `Close()` | 关闭解码器 |

**Push() 处理流程：**

```
1. 检查解码器是否已关闭
2. 创建 AudioData 对象（复制数据）
3. 尝试放入队列
   └── 队列满 → 丢弃最旧的包
```

**注意：** 当前为基础实现，仅存储编码帧数据。实际 Opus 解码需替换为真实解码器实现。

### PCMPlayer — PCM 音频播放器（基础实现）

```go
type PCMPlayer struct {
    buffer chan []byte  // PCM 数据缓冲区
    mu     sync.Mutex
    closed bool
}
```

**构造函数：**

```go
func NewPCMPlayer(capacity int) *PCMPlayer
```

- `capacity`: 缓冲区容量（默认 100）

**方法：**

| 方法 | 说明 |
|------|------|
| `Play(pcm)` | 播放 PCM 数据 |
| `ReadBuffer()` | 读取缓冲区中的 PCM 数据（非阻塞） |
| `Close()` | 关闭播放器 |

**注意：** 当前为基础实现，仅将 PCM 数据写入内部缓冲区。实际播放需替换为 SDL/PulseAudio 绑定。
