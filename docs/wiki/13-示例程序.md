## 1. CLI 入口（cmd/go-scrcpy/main.go）

**功能：** 列举已连接的 Android 设备，选择第一个设备并连接，接收视频帧，每 100 帧打印统计信息。

**流程：**

```
1. 设置日志级别（scrcpy + adb 为 Info）
2. 创建 ADB 客户端
3. 列举设备 → 选择第一个设备
4. 创建 scrcpy 客户端（4Mbps, 无音频, 有帧元数据）
5. 启动客户端
6. goroutine 接收视频帧，每 100 帧打印 PTS/size/config/key
7. 等待 Ctrl+C 退出
```

**关键参数：**
- `VideoBitRate = 4000000` (4Mbps)
- `Audio = false`
- `SendFrameMeta = true`
- 监听端口 `27183`

## 2. 单设备示例（_examples/single）

**功能：** 连接指定序列号的设备，接收视频帧，3 秒后发送 HOME 键。

**流程：**

```
1. 从命令行参数获取设备序列号
2. 创建 ADB 客户端 + scrcpy 客户端
3. 启动客户端
4. goroutine 1: 接收视频帧，每 100 帧打印统计
5. goroutine 2: 等待 3 秒后调用 client.Home()
6. 等待 Ctrl+C 退出
```

## 3. 多设备示例（_examples/multi）

**功能：** 使用 `DeviceTracker` 自动发现设备，每台设备接入后统计帧率并循序执行 8 种控制测试。

**关键特性：**

- 使用 `WatchDevices()` 监听设备上下线
- 每台设备独立 goroutine 处理视频帧
- 每秒报告帧率
- 循序执行 8 种控制测试（每 3 秒一种）：
  1. 展开通知栏
  2. 收起通知栏
  3. HOME 键
  4. BACK 键
  5. POWER 键
  6. 音量加
  7. 音量减
  8. 打开最近任务（Menu 键）

**参数：** `VideoBitRate = 2000000` (2Mbps, 比单设备低以节省带宽)

## 4. 控制示例（_examples/control）

**功能：** 演示 10 种控制功能，按顺序执行，每步间隔 1-2 秒。

**控制序列：**

```
1. HOME 键
2. BACK 键
3. 音量加
4. 音量减
5. 展开通知栏（等待 2 秒）
6. 收起通知栏
7. 文本注入 "Hello from Go-scrcpy!"
8. 启动设置应用 (com.android.settings)
9. 旋转设备
10. 设置剪贴板 "测试文本" + 自动粘贴
```

## 5. 录制示例（_examples/record）

**功能：** 连接设备并录制屏幕，5 秒后截取截图。

**流程：**

```
1. 连接设备
2. 创建 Recorder（recording.mp4）
3. 创建 Screenshot（1920x1080）
4. goroutine 1: 逐帧写入录制文件，每 100 帧打印进度
5. goroutine 2: 5 秒后截取 PNG 截图并保存
6. 等待 Ctrl+C 停止录制
```

## 6. 投屏示例（_examples/mirror）

**功能：** 完整的投屏演示 — 使用 FFmpeg 解码 H.264 视频流，通过 SDL3 窗口渲染显示。

**流程：**

```
1. 列举设备，选择第一个设备
2. adb root（获取 root 权限）
3. 创建 scrcpy 客户端 (4Mbps, 无音频, 有控制)
4. 创建 FFmpeg H264 解码器
5. 遍历视频帧：
   a. 跳过配置帧 (SPS/PPS)
   b. 调用 decoder.Decode() 解码 H264 → YUV420P
   c. 检测分辨率变化 → 重建 SDL 窗口
   d. YUV420PtoRGB() 转换
   e. sdl.RenderYUV() 渲染到窗口
6. 每 100 帧打印渲染统计
```

**依赖：** 需要 `data/scrcpy-win64-v4.1/` 目录下的 FFmpeg (`avcodec-62.dll`, `avutil-60.dll`) 和 SDL3 (`SDL3.dll`)。
