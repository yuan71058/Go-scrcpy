# Go-scrcpy Code Wiki — 录制与截图（pkg/record）

`pkg/record` 提供屏幕录制和截图功能。

## 包结构

```
pkg/record/
├── recorder.go    # Recorder — 视频/音频录制器
└── screenshot.go  # Screenshot — 截图器
```

## 类型定义

### Recorder — 屏幕录制器

```go
type Recorder struct {
    output     io.Writer  // 输出流（文件、网络等）
    format     string     // 格式 ("mp4", "mkv")
    mu         sync.Mutex
    closed     bool
    frameCount int64      // 已录制帧数
}
```

**构造函数：**

```go
func NewRecorder(output io.Writer, format string) *Recorder
func NewRecorderFromFile(path string, format string) (*Recorder, error)
```

- `format`: 录制格式，`"mp4"` 或 `"mkv"`（默认 `"mp4"`）
- `NewRecorderFromFile` 自动创建文件

**方法：**

| 方法 | 说明 |
|------|------|
| `WriteVideo(data, pts, keyframe)` | 写入视频帧 |
| `WriteAudio(data, pts)` | 写入音频数据 |
| `GetFrameCount()` | 获取已录制帧数 |
| `Close()` | 关闭录制器 |

**注意：** 当前为基础实现，直接将编码数据写入输出流。实际应用中应使用 MP4/MKV 容器封装器（如基于 `nareix/joy5` 库的实现）。

### Screenshot — 截图器

```go
type Screenshot struct {
    width  int   // 截图宽度
    height int   // 截图高度
}
```

**构造函数：**

```go
func NewScreenshot(width, height int) *Screenshot
```

**方法：**

| 方法 | 说明 |
|------|------|
| `Capture(data, format)` | 截取当前帧（返回图片字节数据） |
| `SaveToFile(data, path, format)` | 保存截图到文件 |
| `SetSize(w, h)` | 设置截图尺寸 |
| `GetSize()` | 获取截图尺寸 |

**Capture() 支持格式：**
- `"png"` — 使用标准库 `image/png` 编码
- `"jpeg"` — 暂不支持（需 `image/jpeg` 包）

**注意：** 当前为基础实现，生成的是渐变色测试图像而非实际解码帧。实际应用中应从解码后的视频帧生成截图。
