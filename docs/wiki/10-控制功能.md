# Go-scrcpy Code Wiki — 控制功能（pkg/control）

`pkg/control` 提供高级控制功能，包括剪贴板双向同步和文件推送/APK 安装。

## 包结构

```
pkg/control/
├── clipboard.go  # Clipboard 剪贴板管理器 + FilePusher 文件推送器
└── filepush.go   # FilePushHandler 文件推送处理器
```

## 接口定义

### Sender — 控制消息发送器接口

```go
type Sender interface {
    SendControl(msg []byte) error
}
```

所有控制功能通过此接口发送消息，`DeviceSession` 实现了此接口。

## 类型定义

### Clipboard — 剪贴板管理器

```go
type Clipboard struct {
    sender   Sender           // 控制消息发送器
    sequence uint64           // 序列号（单调递增，用于 ACK）
    mu       sync.Mutex
    onChange func(text string)  // 剪贴板变化回调
    closed   bool
}
```

**构造函数：**

```go
func NewClipboard(sender Sender) *Clipboard
```

**方法：**

| 方法 | 说明 |
|------|------|
| `OnChange(fn)` | 设置剪贴板变化回调（当设备剪贴板内容变化时触发） |
| `HandleMessage(msgType, payload)` | 处理从控制通道收到的设备消息 |
| `Close()` | 关闭剪贴板管理器 |

**HandleMessage() 处理的消息类型：**

| 消息类型 | 处理逻辑 |
|----------|----------|
| `0` (TYPE_CLIPBOARD) | 提取文本内容，调用 `onChange` 回调 |
| `1` (TYPE_ACK_CLIPBOARD) | 打印调试日志（含 sequence） |

### FilePusher — 文件推送器

```go
type FilePusher struct {
    sender Sender
    pushID int16
    mu     sync.Mutex
    closed bool
}
```

**构造函数：**

```go
func NewFilePusher(sender Sender) *FilePusher
```

**方法：**

| 方法 | 说明 |
|------|------|
| `HandleMessage(msgType, payload)` | 处理设备消息（文件推送响应） |
| `Close()` | 关闭文件推送器 |

### PushProgress — 推送进度

```go
type PushProgress struct {
    ID        int16   // 推送 ID
    Code      byte    // 状态码
    BytesSent int64   // 已发送字节数
    Total     int64   // 总字节数
}
```

### FilePushHandler — 文件推送处理器

```go
type FilePushHandler struct {
    sender Sender
}
```

**构造函数：**

```go
func NewFilePushHandler(sender Sender) *FilePushHandler
```

**方法：**

| 方法 | 说明 |
|------|------|
| `PushFile(filename, data)` | 推送文件到设备（从 io.Reader 读取数据） |
| `PushFileFromPath(filename, localPath)` | 从文件路径推送文件 |
| `InstallAPK(localPath)` | 安装 APK 文件 |

**PushFile() 协议格式：**

```
[type:102][sub_type:0][filename_len:4][filename:N][data_len:4][data:M]
```

- `sub_type=0` (FilePushNew): 新建推送
- 文件名长度 4 字节 big-endian
- 文件数据长度 4 字节 big-endian

**InstallAPK() 实现：** 调用 `PushFileFromPath("install.apk", localPath)`，将 APK 文件推送到设备。
