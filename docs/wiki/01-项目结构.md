# Go-scrcpy Code Wiki — 项目结构

## 顶层目录

```
go-scrcpy/
├── go.mod                     # Go 模块定义 (module github.com/yuan71058/go-scrcpy)
├── README.md                  # 项目说明文档（中文）
├── cmd/                       # CLI 入口
│   └── go-scrcpy/
│       └── main.go            # CLI 示例程序
├── _examples/                 # 使用示例
│   ├── single/main.go         # 单设备连接示例
│   ├── multi/main.go          # 多设备并发示例
│   ├── control/main.go        # 远程控制示例
│   ├── record/main.go         # 录制与截图示例
│   └── mirror/main.go         # 投屏渲染示例（FFmpeg + SDL3）
├── pkg/                       # 核心库代码
│   ├── scrcpy/                # 核心 API（对外入口）
│   ├── adb/                   # ADB 设备管理
│   ├── server/                # scrcpy-server 生命周期管理
│   ├── transport/             # 三通道 Socket 通信
│   ├── protocol/              # 二进制协议编解码
│   ├── video/                 # 视频解码与 NALU 解析
│   ├── audio/                 # 音频解码与播放
│   ├── input/                 # 输入事件构建
│   ├── control/               # 剪贴板同步与文件推送
│   ├── record/                # 屏幕录制与截图
│   ├── render/                # FFmpeg H264 解码 + SDL3 渲染
│   └── types/                 # 公共类型定义
├── data/                      # 运行时数据
│   ├── scrcpy-server.jar      # Android 端 scrcpy 服务 (733KB)
│   └── scrcpy-win64-v4.1/     # scrcpy v4.1 Windows 二进制文件
└── docs/                      # 文档
    ├── API.md                 # 完整 API 文档
    ├── DEVELOPMENT.md         # 开发计划
    ├── PROTOCOL.md            # 二进制协议规范
    └── wiki/                  # Code Wiki 文档
```

## 各 Package 职责速览

| Package | 路径 | 职责 | 核心文件 |
|---------|------|------|----------|
| `scrcpy` | `pkg/scrcpy/` | 核心 API 入口，对外暴露 Client 和 MultiClient | `client.go`, `session.go`, `multi.go`, `options.go` |
| `adb` | `pkg/adb/` | 封装 ADB 命令行，设备发现与跟踪 | `client.go`, `device.go`, `forward.go` |
| `server` | `pkg/server/` | scrcpy-server 启动/停止/参数管理 | `launcher.go`, `options.go`, `version.go` |
| `transport` | `pkg/transport/` | TCP Listener、三通道 Connection、二进制读写器 | `connection.go`, `reader.go`, `writer.go` |
| `protocol` | `pkg/protocol/` | 握手解析、控制消息构建、设备消息解析、帧头解析 | `handshake.go`, `control_msg.go`, `device_msg.go`, `frame_header.go` |
| `video` | `pkg/video/` | 视频解码器接口、H264 解码器、NALU 解析 | `decoder.go`, `h264.go`, `nalu.go` |
| `audio` | `pkg/audio/` | 音频解码器接口、Opus 解码器、PCM 播放器 | `decoder.go`, `opus.go`, `pcm.go` |
| `input` | `pkg/input/` | 触摸/鼠标/键盘/滚动事件构建、Android Keycode 映射 | `touch.go`, `keycode.go`, `keycode_map.go` |
| `control` | `pkg/control/` | 剪贴板管理、文件推送 | `clipboard.go`, `filepush.go` |
| `record` | `pkg/record/` | MP4 录制、PNG 截图 | `recorder.go`, `screenshot.go` |
| `render` | `pkg/render/` | FFmpeg H264 解码、SDL3 窗口渲染、YUV→RGB 转换 | `decoder.go`, `renderer.go`, `convert.go` |
| `types` | `pkg/types/` | 跨包公共类型 | `device.go`, `codec.go` |

## 文件清单（43 个 Go 源文件）

```
pkg/types/
├── device.go        # Device, DeviceEvent, DeviceInfo, DisplayInfo, ScreenInfo, VideoFrame, AudioPacket
└── codec.go         # VideoCodec, AudioCodec 枚举

pkg/adb/
├── client.go        # ADB Client — ListDevices, Shell, GetDeviceProperties
├── device.go        # DeviceTracker — 实时设备上下线跟踪
└── forward.go       # 端口转发 — Forward, Reverse, Push, Pull, KillServer

pkg/server/
├── version.go       # 版本常量 (ServerVersion = "4.1")
├── options.go       # Options 结构体 (50+ 参数) + ToArgs()
└── launcher.go      # Launcher — Start, Kill, IsRunning

pkg/transport/
├── connection.go    # Listener (reverse tunnel) + Connection (三通道)
├── reader.go        # ProtocolReader — 二进制协议读取器
└── writer.go        # ProtocolWriter — 二进制协议写入器

pkg/protocol/
├── log.go           # 日志函数
├── codec.go         # 所有常量 (编解码器ID, 消息类型, 标志位, 限制值)
├── handshake.go     # 握手数据解析 (设备名, 分辨率)
├── control_msg.go   # 22+2 种控制消息序列化
├── device_msg.go    # 3 种设备消息反序列化
└── frame_header.go  # 帧元数据头解析 (12字节)

pkg/video/
├── decoder.go       # Decoder 接口, DecodedFrame, Renderer 接口
├── nalu.go          # NALU 解析 (H.264/H.265), SPS 解析, Annex B 格式
└── h264.go          # H264Decoder — 通道式帧队列解码器

pkg/audio/
├── decoder.go       # Decoder 接口, Player 接口, AudioData
├── opus.go          # OpusDecoder — 通道式音频包队列
└── pcm.go           # PCMPlayer — 缓冲 PCM 播放器

pkg/input/
├── touch.go         # 触摸/鼠标/滚动事件构建
├── keycode.go       # 按键事件、面板控制、摄像头控制
└── keycode_map.go   # Android KEYCODE_* 常量映射表

pkg/control/
├── clipboard.go     # Clipboard 剪贴板管理器, FilePusher
└── filepush.go      # FilePushHandler 文件推送处理器

pkg/record/
├── recorder.go      # Recorder — 视频/音频录制
└── screenshot.go    # Screenshot — PNG 截图

pkg/scrcpy/
├── log.go           # 日志函数
├── options.go       # Options 包装 + 链式调用方法
├── client.go        # Client — 单设备客户端 (所有输入/控制方法)
├── session.go       # DeviceSession — 设备会话管理
└── multi.go         # MultiClient — 多设备管理器

pkg/render/
├── convert.go       # YUV420P → RGB24 转换 (BT.601)
├── decoder.go       # FFmpeg H264 解码器 (syscall DLL)
└── renderer.go      # SDL3 渲染器 (syscall DLL)

cmd/go-scrcpy/main.go       # CLI 示例入口
_examples/single/main.go     # 单设备示例
_examples/multi/main.go      # 多设备示例
_examples/control/main.go    # 控制示例
_examples/record/main.go     # 录制示例
_examples/mirror/main.go     # 投屏渲染示例
```
