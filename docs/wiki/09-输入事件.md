# Go-scrcpy Code Wiki — 输入事件（pkg/input）

`pkg/input` 提供触摸、鼠标、键盘、滚动等输入事件的构建函数，所有函数返回可直接通过控制通道发送的字节切片。

## 包结构

```
pkg/input/
├── touch.go        # 触摸/鼠标/滚动事件构建
├── keycode.go      # 按键事件、面板控制、显示控制、摄像头控制
└── keycode_map.go  # Android KEYCODE_* 常量映射表
```

## 设计说明

`pkg/input` 是 `pkg/protocol` 控制消息函数的上层封装：
- 提供更友好的函数签名（如 `TouchDown` 隐藏了 `pressure` 等不常用参数）
- 为 `Client` 结构体的便捷方法提供底层实现
- 所有函数返回 `[]byte`，可直接通过 `SendControl()` 发送

## 输入事件函数

### 触摸事件

| 函数 | 说明 | 关键参数 |
|------|------|----------|
| `TouchDown(pointerID, x, y, screenW, screenH)` | 触摸按下 | pressure=0xFFFF (1.0) |
| `TouchMove(pointerID, x, y, screenW, screenH)` | 触摸移动 | pressure=0xFFFF (1.0) |
| `TouchUp(pointerID, x, y, screenW, screenH)` | 触摸抬起 | pressure=0x0000 (0.0) |
| `TouchCancel(pointerID, x, y, screenW, screenH)` | 触摸取消 | pressure=0x0000 (0.0) |

**参数：**
- `pointerID`: `0xFFFFFFFFFFFFFFFF` = 鼠标, `0xFFFFFFFFFFFFFFFE` = 通用手指
- `x, y`: 触摸坐标（相对于屏幕）
- `screenW, screenH`: 屏幕尺寸（用于坐标归一化）

### 鼠标事件

| 函数 | 说明 | 关键参数 |
|------|------|----------|
| `MouseDown(x, y, screenW, screenH, button)` | 鼠标按下 | 使用 PointerIDMouse |
| `MouseMove(x, y, screenW, screenH, buttons)` | 鼠标移动 | buttons 为按钮状态位掩码 |
| `MouseUp(x, y, screenW, screenH, button)` | 鼠标抬起 | 使用 PointerIDMouse |

**button 参数：** `1`=左键, `2`=右键, `4`=中键

### 滚动事件

```go
func Scroll(x, y int32, screenW, screenH uint16, hscroll, vscroll int16) []byte
```

- `hscroll`: 水平滚动量（正数向右, 负数向左）
- `vscroll`: 垂直滚动量（正数向下, 负数向上）

### 按键事件

| 函数 | 说明 |
|------|------|
| `KeyDown(keycode, meta)` | 按键按下 |
| `KeyUp(keycode, meta)` | 按键抬起 |
| `KeyPress(keycode, meta)` | 完整按键（按下+抬起，返回 `[][]byte`） |
| `Text(text)` | 文本注入（最长 300 字节） |
| `BackOrScreenOn(action)` | 返回键/亮屏 |
| `BackPress()` | 返回键完整事件（按下+抬起） |

**参数：**
- `keycode`: Android KEYCODE_* 常量（见 keycode_map.go）
- `meta`: 修饰键状态位掩码

### 修饰键常量（Meta）

```go
const (
    MetaNone         int32 = 0
    MetaAltLeft      int32 = 0x10
    MetaAltRight     int32 = 0x20
    MetaShiftLeft    int32 = 0x40
    MetaShiftRight   int32 = 0x80
    MetaCtrlLeft     int32 = 0x1000
    MetaCtrlRight    int32 = 0x2000
    MetaMetaLeft     int32 = 0x10000
    MetaMetaRight    int32 = 0x20000
    MetaCapsLock     int32 = 0x100000
    MetaNumLock      int32 = 0x200000
    MetaScrollLock   int32 = 0x400000
)
```

## Android Keycode 映射

`keycode_map.go` 定义了完整的 Android `KEYCODE_*` 常量映射，包括：

- 字母键：`KeycodeA`(29) ~ `KeycodeZ`(54)
- 数字键：`Keycode0`(7) ~ `Keycode9`(16)
- 功能键：`KeycodeHome`(3), `KeycodeBack`(4), `KeycodePower`(26), `KeycodeMenu`(82)
- 方向键：`KeycodeDPadUp`(19), `KeycodeDPadDown`(20), `KeycodeDPadLeft`(21), `KeycodeDPadRight`(22)
- 音量键：`KeycodeVolumeUp`(24), `KeycodeVolumeDown`(25)
- 媒体键：`KeycodeMediaPlayPause`(85), `KeycodeMediaStop`(86), `KeycodeMediaNext`(87)
- 功能键：`KeycodeF1`(131) ~ `KeycodeF12`(142)
- 小键盘：`KeycodeNumpad0`(144) ~ `KeycodeNumpad9`(153)

并提供 `KeyCodeToName` 映射表和 `GetNameByKeycode(keycode)` 查询函数。
