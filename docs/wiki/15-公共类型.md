# Go-scrcpy Code Wiki — 公共类型（pkg/types）

`pkg/types` 定义跨包使用的公共类型，包括设备信息、显示信息、编解码器枚举等。

## 包结构

```
pkg/types/
├── device.go    # Device, DeviceEvent, DeviceInfo, DisplayInfo, ScreenInfo, VideoFrame, AudioPacket
└── codec.go     # VideoCodec, AudioCodec 枚举
```

## 类型定义

### Device — ADB 设备信息

```go
type Device struct {
    Serial    string  // 设备序列号（如 "emulator-5554"）
    State     string  // 设备状态: "device", "offline", "bootloader"
    Model     string  // 设备型号（如 "Pixel 6"）
    Product   string  // 产品名称
    Transport string  // 传输方式（如 "usb:", "tcp:192.168.1.100:5555"）
}
```

### DeviceEvent — 设备上下线事件

```go
type DeviceEvent struct {
    Type   EventType  // 事件类型
    Device Device     // 关联的设备信息
}
```

### EventType — 设备事件类型

```go
const (
    EventDeviceAdded   EventType = iota  // 设备上线
    EventDeviceRemoved                   // 设备离线
    EventDeviceChanged                   // 设备状态变化
)
```

### DeviceInfo — 设备详细信息

```go
type DeviceInfo struct {
    Serial        string            // 设备序列号
    Model         string            // 设备型号
    AndroidVersion int              // Android 版本号
    SDKVersion    int               // SDK 版本号
    Properties    map[string]string // 设备系统属性
}
```

### DisplayInfo — 显示器信息

```go
type DisplayInfo struct {
    DisplayID  int32  // 显示器 ID (0 = DEFAULT_DISPLAY)
    Width      int32  // 宽度 (像素)
    Height     int32  // 高度 (像素)
    Rotation   int32  // 旋转 (0, 1, 2, 3)
    LayerStack int32  // 图层栈
    Flags      int32  // 标志位
}
```

**显示器标志位常量：**

```go
const (
    FlagSupportsProtectedBuffers int32 = 0x001  // 支持受保护缓冲区
    FlagSecure                   int32 = 0x002  // 安全显示
    FlagPrivate                  int32 = 0x004  // 私有显示
    FlagPresentation             int32 = 0x008  // 演示显示
    FlagRound                    int32 = 0x010  // 圆形显示
)
```

### ScreenInfo — 屏幕信息

```go
type ScreenInfo struct {
    ContentRect   Rect   // 内容区域
    VideoSize     Size   // 视频尺寸
    DeviceRotation uint8  // 设备旋转
}
```

### Rect — 矩形区域

```go
type Rect struct {
    Left   int32
    Top    int32
    Right  int32
    Bottom int32
}
```

### Size — 尺寸

```go
type Size struct {
    Width  int32
    Height int32
}
```

### VideoFrame — 视频帧

```go
type VideoFrame struct {
    PTS    int64   // 显示时间戳 (微秒)
    Data   []byte  // 原始编码数据
    Width  int     // 帧宽度
    Height int     // 帧高度
    Config bool    // 是否为配置帧 (SPS/PPS)
    Key    bool    // 是否为关键帧
}
```

### AudioPacket — 音频包

```go
type AudioPacket struct {
    PTS  int64   // 显示时间戳 (微秒)
    Data []byte  // 编码数据
}
```

### VideoCodec — 视频编解码器枚举

```go
type VideoCodec int

const (
    VideoCodecH264 VideoCodec = iota  // H.264/AVC
    VideoCodecH265                    // H.265/HEVC
    VideoCodecAV1                     // AV1
    VideoCodecVP8                     // VP8
    VideoCodecVP9                     // VP9
)
```

**String() 返回值：** `"h264"`, `"h265"`, `"av1"`, `"vp8"`, `"vp9"`, `"unknown"`

### AudioCodec — 音频编解码器枚举

```go
type AudioCodec int

const (
    AudioCodecOpus AudioCodec = iota  // Opus
    AudioCodecAAC                     // AAC
    AudioCodecFLAC                    // FLAC
    AudioCodecRAW                     // PCM 原始音频
)
```

**String() 返回值：** `"opus"`, `"aac"`, `"flac"`, `"raw"`, `"unknown"`
