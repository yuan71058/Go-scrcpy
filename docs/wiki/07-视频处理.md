# Go-scrcpy Code Wiki — 视频处理（pkg/video）

`pkg/video` 提供视频解码接口、H.264 解码器实现以及 NALU（Network Abstraction Layer Unit）解析功能。

## 包结构

```
pkg/video/
├── decoder.go    # Decoder 接口、DecodedFrame 结构体、Renderer 接口
├── nalu.go       # NALU 类型常量、解析器、SPS 解析、Annex B 格式工具
└── h264.go       # H264Decoder — 通道式帧队列解码器
```

## 接口定义

### Decoder — 视频解码器接口

```go
type Decoder interface {
    Push(data []byte) error           // 推送编码数据到解码器
    ReadFrame() (*DecodedFrame, error) // 读取解码后的帧（阻塞）
    Close() error                      // 关闭解码器
}
```

用户可以替换此接口的自定义实现（如 FFmpeg CGo 绑定）。

### Renderer — 渲染器接口

```go
type Renderer interface {
    Render(frame *DecodedFrame) error  // 渲染一帧
    Close() error                      // 关闭渲染器
}
```

## 类型定义

### DecodedFrame — 解码后的视频帧

```go
type DecodedFrame struct {
    PTS    int64   // 显示时间戳 (微秒)
    Data   []byte  // 原始编码数据（NALU）
    Width  int     // 帧宽度
    Height int     // 帧高度
    Config bool    // 是否为配置帧 (SPS/PPS)
    Key    bool    // 是否为关键帧
}
```

### NALU — 网络抽象层单元

```go
type NALU struct {
    Type     NALUType  // NALU 类型
    Data     []byte    // NALU 数据（不含 start code）
    Temporal int       // 时域层 ID
}

type NALUType int
```

**H.264 NALU 类型常量：**

| 常量 | 值 | 说明 |
|------|----|------|
| `NALUTypeH264Unspecified` | 0 | 未指定 |
| `NALUTypeH264NonIDR` | 1 | 非 IDR 帧 |
| `NALUTypeH264IDR` | 5 | IDR 帧（关键帧） |
| `NALUTypeH264SEI` | 6 | 补充增强信息 |
| `NALUTypeH264SPS` | 7 | 序列参数集 |
| `NALUTypeH264PPS` | 8 | 图像参数集 |
| `NALUTypeH264AUD` | 9 | 访问单元分隔符 |

**H.265/HEVC NALU 类型常量：**

| 常量 | 值 | 说明 |
|------|----|------|
| `NALUTypeH265VPS` | 32 | 视频参数集 |
| `NALUTypeH265SPS` | 33 | 序列参数集 |
| `NALUTypeH265PPS` | 34 | 图像参数集 |
| `NALUTypeH265IDR_W_RADL` | 19 | IDR 帧 |
| `NALUTypeH265IDR_N_LP` | 20 | IDR 帧 |

**NALUType 方法：**

| 方法 | 说明 |
|------|------|
| `String()` | 返回 NALU 类型名称 |
| `IsConfig()` | 是否为配置 NALU (SPS/PPS/VPS) |
| `IsKeyFrame()` | 是否为关键帧 NALU |

## 关键类型

### H264Decoder — H.264 解码器（基础实现）

```go
type H264Decoder struct {
    frames   chan *DecodedFrame  // 解码后的帧队列
    closed   chan struct{}       // 关闭信号
    width    int                 // 视频宽度
    height   int                 // 视频高度
    mu       sync.Mutex
    spsData  []byte             // SPS 数据
    ppsData  []byte             // PPS 数据
}
```

**构造函数：**

```go
func NewH264Decoder(capacity int) *H264Decoder
```

- `capacity`: 帧队列容量（默认 60）

**核心方法：**

| 方法 | 说明 |
|------|------|
| `Push(data)` | 推送编码数据到解码器 |
| `ReadFrame()` | 读取帧（阻塞） |
| `Close()` | 关闭解码器 |
| `SetSize(w, h)` | 设置视频尺寸 |
| `GetSize()` | 获取视频尺寸 |
| `GetSPS()` | 获取 SPS 数据 |
| `GetPPS()` | 获取 PPS 数据 |

**Push() 处理流程：**

```
1. 检查解码器是否已关闭
2. 检查数据是否包含 SPS/PPS → 设置 isConfig
3. 检查是否为关键帧 → 设置 isKey
4. 解析 NALU，保存 SPS/PPS 数据
5. 创建 DecodedFrame 对象
6. 尝试放入队列
   └── 队列满 → 丢弃最旧的帧
```

### NALUReader — NALU 读取器

```go
type NALUReader struct {
    data   []byte  // Annex B 格式的原始数据
    offset int     // 当前解析偏移
}
```

**构造函数：**

```go
func NewNALUReader(data []byte) *NALUReader
```

**核心方法：**

| 方法 | 说明 |
|------|------|
| `Next()` | 读取下一个 NALU（返回 *NALU, bool） |
| `findStartCode()` | 查找 `0x000001` 或 `0x00000001` start code |
| `findNextStartCode()` | 查找下一个 start code 位置 |
| `parseNALU(data, startCodeLen)` | 解析 NALU 头（提取类型和时域层 ID） |

**Annex B 格式解析：**

```
[00 00 00 01] [NALU header] [NALU payload] [00 00 00 01] [next NALU] ...
      ↑              ↑
  start code      NALU 数据
```

NALU 头解析：
- **H.264**: 低 5 位为 NALU 类型
- **H.265**: 第 2-7 位为 NALU 类型（需注意）

### 工具函数

| 函数 | 说明 |
|------|------|
| `ParseSPS(data)` | 解析 H.264 SPS NALU（简化实现，仅提取基本信息） |
| `SplitFrameData(data)` | 将帧数据分割为独立 NALU 列表 |
| `HasSPSPPS(data)` | 检查帧数据是否包含 SPS/PPS |
| `IsKeyFrame(data)` | 检查帧数据是否为关键帧 |
| `ConcatNALUs(nalus)` | 连接多个 NALU 为 Annex B 格式 |
